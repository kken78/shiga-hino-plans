# 日野町の計画ダッシュボード集（プロトタイプ）

滋賀県日野町の各種行政計画のデータを抽出し、視覚的にわかりやすく閲覧できるように構築した、公開資料の利活用のための実証実験プロジェクトです。

出力はフレームワーク・CDN・外部フォントを使わない自己完結HTMLで、`file://` で開いても GitHub Pages でも動作します。データ（JSON）を唯一の真実の源として、図表を数値から生成しています。

**公開版**: https://kken78.github.io/shiga-hino-plans/

## 🚀 主な特徴

1. **2層構成** — 43計画を俯瞰する「計画ライブラリ」と、計画ごとに深掘りする「計画別ダッシュボード」の2層。43計画のうち41計画にダッシュボードがあります（残る2計画は文書が公開されていないため作っていません）。
2. **出典の明示（捏造禁止）** — すべてのデータブロックに出典（文書＋ページ）を併記。原典で確認できない数値・固有名詞・年度は書かず、欠けたまま出します。
3. **図表は数値から計算生成** — バー幅・座標・達成率を手書きせず、データ（JSON）から計算して描画します。
4. **原典との照合** — 描画と同時に照合表（`build/audit/<id>.tsv`）を出力し、原典PDFと値・単位・出典ページを1件ずつ照らしています。照合の状況（何件のうち何件が済んだか）は、各計画ページの上部と末尾、ハブの計画カードに表示しています。
5. **vanilla 自己完結** — 出力は単一HTML。`file://` で開いてもそのまま動くので、オフラインでも閲覧できます。

## 📚 収録内容

### 計画ライブラリ（43計画・9分野）

`docs/index.html` に43計画のカードを、9分野で分類して掲載しています。

- 総合・まちづくり ／ 都市・住まい ／ 交通・道路 ／ 環境・ごみ ／ 健康・福祉 ／ 子育て・教育・文化 ／ 防災・安全 ／ 行政運営 ／ 産業・農林業
- 個別ダッシュボードが未整備の計画は、カード（および図解モーダル）での表示にとどまります。

### 計画別ダッシュボード（41計画）

- `docs/plans/<id>.html` に、43計画のうち41計画のダッシュボードがあります（例：第3期 日野町子ども・子育て支援事業計画 `docs/plans/kodomo.html`）。全データに出典を併記しています。
- 原典との照合は4段で行っています（段1 プログラム、段2 AI（2回）、段3 文章の点検、段4 人による確認）。2026年11月6日時点で、41計画とも段1〜3が済み、残っているのは段4（人による確認）です。段4まで済んだ計画は10計画です。

## 🛠️ ローカルでの確認

出力は自己完結HTMLのため、**簡易サーバは不要**です（実行時 `fetch` を使いません）。

- ハブ：`docs/index.html` をブラウザで開く
- 計画ページ：`docs/plans/kodomo.html` を開く

計画を1本追加するときの定型フロー：

```bash
# 1) 原典PDFをローカル作業用の sources_raw/<id>/（リポジトリには含めない）に置き、
#    PLAN_SCHEMA.md に従って data/plans/<id>.json を起票
python3 tools/validate_schema.py data/plans/<id>.json   # 2) スキーマ検証
python3 tools/render_plan.py <id>                        # 3) 描画＋照合表生成
node   tools/validate.mjs docs/plans/<id>.html           # 4) 出力検証
python3 tools/build.py                                   # 5) ハブへ登録・再生成
# 6) build/audit/<id>.tsv を原典PDFと人が突合（検収）
```

`sources_raw/`（原典PDF置き場）はリポジトリに含めていません。

ページの上の共通の見出し・分野のナビ・ページの一覧と、フッターは、日野町データポータルの共通の部品で、`templates/portal/` は hino-portal の `shared/` の正本の写しです（DESIGN.md ADR-12）。正本と同じかは `python3 <hino-portal のフォルダ>/shared/check.py docs/index.html docs/plans/*.html` で確かめます（CI でも実行します）。

SNS などでリンクを共有したときに出る画像（OGP 画像）は `docs/og.png`（1200×630）で、ハブと各計画ページで同じものを使います。編集元は `templates/og.svg` です。作り直し方は hino-portal の README の「OGP 画像の作り直し方」にあります。

## ⚠️ 免責事項

- **データの正確性:** 本リポジトリのデータは、公開されている原典（PDF等）から独自に抽出・構造化したものです。読み取り誤差や変換ミスを含む可能性があるため、正確な数値が必要な場合は必ず日野町公式の元資料をご確認ください。各計画には出典（文書・ページ）を併記しています。
- **照合の状況:** 計画別ダッシュボードの数値は、原典との照合（段1〜3）を終えていますが、人による確認（段4）が済んでいない計画があります。各計画ページの「原典との照合」で、照合が済んでいない件数とその理由を確かめられます。
- **位置づけ:** 本プロジェクトは日野町の公式システムではなく、公開資料の利活用を進めるための実証実験（プロトタイプ）です。予告なく仕様変更・公開停止する場合があります。

### 原典について

このリポジトリは原典の PDF を含みません（原典の PDF から取り出した文字は data/text/・data/text_raw/ に含みます）。原典の PDF から切り出した図のうち、町が作成したとみられる模式図8点だけを、出典を付けて掲載しています。地図を下図にした図や写真は掲載せず、原典の該当ページへのリンクにしています。

### 町のサイトの巡回

毎週月曜 7:00（JST）に、GitHub Actions（`.github/workflows/watch.yml`）が町のサイトを巡回し、原典の台帳 `data/sources_index.tsv` との違いを Issue にします。道具は `tools/watch_sources.py`（標準ライブラリだけ。取得は1秒に1件以内）です。

| 見つけるもの | 確かめ方 |
|---|---|
| 差し替え | 台帳の URL（145件）に HEAD を送り、Content-Length が台帳の bytes と同じで Last-Modified が取得日より後でなければ変更なしとします。それ以外は GET して sha256 を比べます |
| 取れない | 台帳の URL が 404 などで取れない |
| 新しい PDF | 計画の掲載ページ（42ページ）に、台帳に無い PDF のリンクがある |

巡回は見つけるだけで、台帳・計画の JSON・検収の台帳・原典の文字は変えません。Webアーカイブから取った原典（台帳の note が「取得元：Webアーカイブ」）と、当初予算の附表の掲載ページ（補正予算の概要など、この台帳の対象でない PDF が多いため。新しい年度の附表は hino-budget の側で見る）は対象から外しています。巡回そのものに失敗したとき（掲載ページが取れない、通信の失敗が2割以上）は、ワークフローが失敗して「巡回に失敗した」Issue ができます。同じ内容の Issue が開いていれば作りません。

Issue が来たら、本文の「次にやること」に従います。差し替えなら原典を取り直して台帳と原典の文字を直し、起票と検収（CLAUDE.md の定型フロー 6）をやり直すか、前の版として残します（PLAN_SCHEMA §10.3）。新しい PDF なら、計画の本編・概要版・資料編・改定版かを見て、対象なら定型フローで起票します。対象外（議事録・様式・お知らせなど）なら `data/watch_ignore.tsv` に url・reason・date を足します（足さないと次の週にまた Issue ができます）。

手元で確かめるときは `python3 tools/watch_sources.py`（約4分）です。`--only head`・`--only pages`・`--limit N --offset M` で範囲を絞れます。同じ大きさで差し替えられ、Last-Modified も取得日より前のものは HEAD では見つからないので、改定の見落としを疑うときは `--full`（全部 GET。約 760MB）で確かめます。定期実行は60日間コミットが無いと止まるため、`.github/workflows/keepalive.yml` が毎月1日に有効化し直します。
