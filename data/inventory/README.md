# 原典の所在一覧(plan_sources.tsv)

`data/manifest.json` に載っている43計画について、町の掲載ページにある PDF リンクを一覧にしたもの。
PDF そのものはダウンロードしていない(リンクとサイズ表示の記録のみ)。

## 取得条件

- 取得日: 2026-10-09
- 取得元: `data/manifest.json` の各計画の `url`(日野町ホームページの掲載ページ)
- 取得方法: 各ページの HTML から、リンク先が `.pdf` の `<a>` を抜き出した。同じページ内の同一 URL は1行にまとめた
- ページの取得は1件ごとに2.5秒あけた(町のサイトへの負荷を避けるため)

## 列の意味

| 列 | 意味 |
|---|---|
| `id` | 計画 id(`data/manifest.json` の `id`) |
| `name` | 計画名(`data/manifest.json` の `name`) |
| `page_url` | 掲載ページの URL(`data/manifest.json` の `url`) |
| `link_text` | ページ上のリンク文字列(タグを除き、空白をまとめたもの) |
| `pdf_url` | PDF の URL(相対リンクは絶対 URL に直した) |
| `size` | リンク文字列に書かれていたサイズ表示(例 `803.01KB`)。表示が無ければ空欄 |

1行目は列名。計 132 行(40計画分)。
