分野別の個別計画環境・教育・防災・住宅など。多くは5〜10年の期間を持つ

個別計画は法律にもとづくものが多く、期間が来ると「第◯期」として作り直されます。「まもなく満了」は次の計画づくり（住民意見の募集など）が始まるサインです。

このライブラリの読み方

各計画には、ひと目でわかる「やさしい概要」と、基本目標や柱を並べた「この計画のポイント」を載せています。まず概要で全体像をつかみ、気になったら公式ページで全文を確認する——という順路を想定しています。

計画期間の帯（進捗バー）は、町の公表ページ本文で期間を確認できた計画にのみ表示しています。確認できていない計画は「期間は資料参照」と明示しています。数値目標など詳しい内容は、順次、原典から追記していく前提です。

正確な内容は必ず町の公式ページでご確認ください。

このサイトについて

日野町の公開資料をもとに作成した実証実験プロトタイプ（非公式）です。計画は町の「施策・計画」ページおよび各部門別ページ、人口は「日野町人口情報の詳細」を出典としています。
