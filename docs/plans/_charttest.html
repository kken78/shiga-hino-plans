このページについて

このページは、滋賀県日野町 政策参与の東健二郎が、個人として作成した試作です。日野町の公式のサイトではなく、町の見解を示すものでもありません。

計画の原典（町のホームページで公開されている PDF など）から、数値と文章を計画ごとの JSON に転記し、図表はその数値からプログラムで描いています。数値には、原典の資料名とページを添えています。

出典
  • テストデータ(架空)
  • テスト用の原典(架空・PDF)
注意

内容の正確性を保証するものではありません。最新・正確な情報は日野町の公式ページでご確認ください。
